    The honest scoreboard

    Every BC Transit arrival prediction is recorded, then checked against when the bus actually got there. bide's models answer exactly the same questions, using only what was known at the time.

    How it's scored

    bide is independent: it uses the timetable and the bus's own reported progress. bide+ blends BC Transit's prediction, bide's and the timetable, with weights for each lead time learned on an earlier day. Both notice when the feed's clock is a whole hour out and correct it. Settings are always learned on a previous day, never the day being scored.
